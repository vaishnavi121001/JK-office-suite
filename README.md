# 🏢 JK Office Suite

A multi-role enterprise office management system built with Django and Django REST Framework.

## 🚀 Features

### Authentication
- Multi-role login
- Email verification
- Role-based access control

### Attendance
- QR Code Attendance
- Attendance Tracking
- Daily Reports

### HR Module
- Employee Management
- Salary Management
- Payslip Generation
- Recruitment Workflow

### Manager Module
- Task Assignment
- Team Monitoring
- Leave Approvals

### Staff Module
- Task Execution
- Work Submission
- Attendance Tracking

### Director Dashboard
- Organization Analytics
- Attendance Insights
- Employee Monitoring

---

## 🛠 Tech Stack

- Python
- Django
- Django REST Framework
- HTML
- CSS
- Bootstrap
- MySQL

---
## 🏗 Architecture

The JK Office Suite follows a role-based architecture where Directors, HRs, Managers, and Staff interact through centralized authentication, attendance, payroll, leave management, and workflow modules.
